# 最终幻想7 资料站

这是一个静态中文网站，把 zzhx 这个 Android 应用里的最终幻想7 资料做成可以在浏览器里看的页面。文案来自应用的 `strings.xml`、`arrays.xml` 和各页面布局，图片来自应用的 drawable（角色图、背景图、首页横幅、海报等）。

## 怎么打开

不需要安装依赖，也不需要构建。

1. 克隆或下载这个仓库。
2. 用浏览器直接打开根目录的 `index.html`。
3. 如果要给别人看，也可以用任意静态文件服务器指向这个目录。GitHub Pages 会从 `main` 分支的根目录提供页面。

## 页面

- 首页
- 游戏简介
- 角色设定（列表和每人的详情）
- 角色背景
- 游戏评价（写评价只保存在浏览器 localStorage，没有后端）
- 热门电影：只保留搜索和列表的版式

## 密钥

仓库里没有 TMDB API 密钥，也没有 `local.properties`。电影页因此没有接上实时数据，也不会用编造的影片冒充接口结果。

## 和原应用不完全一样的地方

- 简介里的日文版发售日期写为 1997年1月31日。原应用简介字符串里的英文名拼写有误，这里改为 Final Fantasy VII。
- 角色列表包含资料数组的第一条「克劳德」。这一条和「克劳德·斯特莱夫」用的是同一张 `role_cloud.jpg`，网站没有换成别的图。
